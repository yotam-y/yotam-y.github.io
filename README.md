# yotam-y.github.io

Personal portfolio site for Yotam Yellin. Plain static HTML/CSS/JS, no build step.

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/

## Deploy

Pushing to `main` publishes automatically to https://yotam-y.github.io/ via GitHub Pages.

## Updating content

Edit `index.html` directly. Replace `assets/resume.pdf` to update the downloadable resume.
